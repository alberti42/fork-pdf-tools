* Fixes with no pull request yet

** Compressed, encrypted or inside-archive PDFs, on top of #335

- fix(pdf-view): keep the server's copy in step when saving.  Saving a
  .pdf.gz twice, with one highlight added each time, ended with a file that
  had the second and not the first.
- fix(pdf-view): write through the file handlers, not through the buffer.
  Saving no longer replaces the buffer, so it no longer costs the page
  overlays under ~pdf-view-roll-minor-mode~.
- fix(pdf-view): give the write epa's settings from this buffer.  Saving an
  encrypted PDF stopped to ask for the recipients on every save.
- fix(pdf-view): ask for ~epa-inhibit~ the way that does not warn.
- Tests for saving a compressed, a gpg-encrypted and an in-archive document.

** pdf-roll

- fix(pdf-roll): redisplay every window when WINDOW is t.  Toggling
  ~pdf-view-midnight-minor-mode~ from another window, or from a hook, did not
  redraw the PDF until its window was selected.
- fix(pdf-roll): give ~setq-local~ one pair at a time.  pdf-roll.el did not
  byte-compile on Emacs 26.3.

** Other

- fix(pdf-util): convert the page the window is showing.  ~pdf-annot-edit~
  failed in a window that had only drawn the page in roll mode:
  =Wrong type argument: char-or-string-p, nil=.
- fix: use ~when-let*~, which ~when-let~ became.  Emacs 31 made ~when-let~
  obsolete.
- feat(pdf-history): keep one provisional item while browsing a list.  While
  a follow mode moves the document, the history keeps one item for where
  browsing landed and replaces it on the next move, so =B= returns to the
  position you were reading.  This changes what the history records, so it
  will get its own pull request, after #371.
